# Bypass
This skill allows you to ignore ICE in the first node of a site: the node where you connected to the site. This is normally the start node,
but when you connect via an [uplink](../layers/Uplink.md) it is the node where the uplink brings you.

- You can move to other nodes from the first node. 
- You can also perform a scan inside the first node to reveal the site beyond this node. Normally the ICE blocks revealing the rest of the site.
